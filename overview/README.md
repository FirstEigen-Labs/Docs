# Welcome to FirstEigen

FirstEigen builds tools that help teams trust their data and their AI. Our products find data quality problems automatically, enforce rules on AI agents at runtime, and let you ask questions about your data in plain language.

## Our products

| Product | What it does | Status |
| --- | --- | --- |
| DataBuck SDK | Auto-discovers data quality rules and validates data where it lives, including Databricks and Microsoft Fabric | Available |
| AgentBuck SDK | A runtime enforcement layer that keeps AI agents within defined policies | Coming soon |
| MCP | An MCP-based Data Trust Agent for querying data trust and quality through chat | Coming soon |

## Where to start

* New to FirstEigen? Pick a product tab above.
* Want to try something now? Open **DataBuck SDK**, then **Integrations > Databricks**.
